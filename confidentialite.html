Confidentialité

Vos fichiers restent chez vous

Décrasse a été conçu pour que vos données ne quittent jamais votre ordinateur. Voici exactement ce qui se passe.

Ce que fait Décrasse

  • Les fichiers que vous déposez sont lus et nettoyés par votre navigateur, sur votre appareil.
  • Aucun fichier, aucune cellule, aucun nom de fichier n'est transmis à un serveur.
  • Le fichier propre est créé sur votre appareil, puis téléchargé directement.
  • Quand vous fermez l'onglet, tout disparaît : rien n'est conservé.

Ce que Décrasse ne fait pas

  • Pas de compte, pas de courriel demandé.
  • Pas de témoins (cookies) publicitaires ni de suivi publicitaire.
  • Pas de revente ni d'analyse de vos données.

Ressources externes

La page charge ses polices de caractères depuis Google Fonts. Pour les anciens fichiers .xls seulement, un lecteur open source (SheetJS) est téléchargé depuis un réseau de diffusion de contenu. Ces services reçoivent l'adresse IP de votre navigateur, comme pour tout site Web, mais jamais le contenu de vos fichiers.

Hébergement

Le site est servi comme un ensemble de fichiers statiques. L'hébergeur peut tenir des journaux techniques standards (adresse IP, page demandée, date), sans accès à vos fichiers.

Nous joindre

Pour toute question sur la confidentialité, écrivez à contact@decrasse.ca.
